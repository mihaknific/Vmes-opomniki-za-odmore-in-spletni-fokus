# Mozilla Add-ons listing draft — English

## Name
Vmes: Break Reminders & Website Focus

## Short description
Custom reminders for eye breaks, hydration, and stretching, plus website limits. Private, with no account or analytics.

## Category
Productivity

## Full description
Vmes: Break Reminders & Website Focus is a Firefox extension for healthier breaks and fewer browsing distractions. Set reminders for eye breaks, hydration, and stretching; set daily time limits for selected websites or block them. Use either feature on its own or combine them. Time is counted only in the active tab. Your data stays in Firefox — no account, tracking, or remote servers.

Create:
- interval reminders,
- one-time reminders,
- daily and weekly schedules,
- website-specific reminders based on focused active-tab time,
- daily time limits for selected websites,
- strict blocks for sites you want to keep out of your workday.

Everything stays local in Firefox. Your reminders, website rules, settings, history, and site-time usage remain in the extension’s own storage and are not sent to a server.

Choose how you want to be reminded:
- native system notification,
- in-page reminder overlay,
- dedicated reminder window,
- or a combination of channels.

## Privacy
Vmes: Break Reminders & Website Focus does not send your browsing data, reminder content, website rules, history, or active site-time to any remote service. The data stays local to Firefox extension storage.

Website reminders and focus rules request access only to the selected domains, when you add or enable those features.

## Permissions
- `alarms`: schedule reminders.
- `notifications`: show system notifications.
- `storage`: store settings, reminders, and history.
- `tabs` and `windows`: detect active tabs and focus for site-time tracking.
- `scripting`: inject a reminder UI into a page after the user grants access.
- optional host permissions: only for website-dependent features.

## Highlights
- no account required,
- no analytics or ads,
- local-first storage,
- multiple reminder types,
- daily time limits and blocking for selected sites,
- reminders based on focused active-tab time,
- calm workflow support for focused work.
